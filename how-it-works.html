How it works

From corner coordinates to a registered plot.

Six steps, from typing the corners to sealing the record.

  1. Choose the coordinate type

    Pick latitude and longitude (from a GPS), or UTM metres (from a survey). Choose the same type your instrument exported. A wrong UTM zone is the easiest mistake to make, so the system warns you when a plot lands outside Nigeria.

  2. Enter or upload the corners

    Type one corner per line, with at least three corners. Or upload a CSV file with the corners in the same order. Latitude comes first for lat/long, and easting comes first for UTM.

  3. Check for overlap

    A green tick means 0 overlap, so the plot can be registered. A red X means it shares area with a registered plot. The result names that plot and the overlap in square metres. Plots that only touch along a shared boundary are not counted as overlapping.

  4. Register the plot

    With the admin key, a clear plot gets a unique title code such as SABA-NAUB-RES-001. The first five real NAUB plots fill the reserved pilot slots in order, and the button asks you to tap twice so a slot is never used by accident.

  5. Add a beacon photo

    Upload a photo taken at the beacon. The system reads its GPS tag and tells you how many metres from the plot it was taken. If it is far, check it was taken at the right place.

  6. Seal it in the ledger

    Every registration joins a ledger in which each record carries the fingerprint of the one before it. Check ledger recalculates the chain and tells you if anything was changed or deleted. Anchor to Polygon posts the latest fingerprint on a public test network, so history cannot be quietly rewritten.

Reading the map

  • Bright cyan: a registered plot from field data.
  • Soft blue: synthetic test data.
  • Green with a tick: the plot you checked, with no overlap.
  • Red with an X: the plot overlaps registered land.

For clients and real estate companies

Pay the token fee, and you receive a login code and a payment receipt that anyone can verify. Use the code on the Register New Plot page to check your plot for overlap and register it. Each registered plot gets its own title code.

Plots are stored as WGS84 latitude and longitude. Areas and overlaps are measured in metres, using each plot's own UTM zone.
